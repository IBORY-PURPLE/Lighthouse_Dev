# LightHouse AI 멀티턴 음성 MVP

기존 LightHouse 5개 화면을 유지하고, 고정 질문 대신 OpenAI Responses API를 호출합니다. API 키는 **서버에서만** 사용합니다.

## 시작 (Node.js 20.6 이상)

1. `.env.example`을 복사해 `.env`로 이름을 바꿉니다.
2. `.env`의 `OPENAI_API_KEY`에 실제 키를 입력합니다. **키를 다른 사람에게 공유하거나 Git에 업로드하지 마세요.**
3. 프로젝트 폴더에서 `npm start` 실행.
4. 브라우저에서 `http://localhost:3000` 접속.

설치할 npm 패키지는 없습니다. 키 발급 및 API 결제 설정은 OpenAI 플랫폼에서 별도로 해야 합니다.

## 구현 범위

- 실제 AI 기반 멀티턴 질문, 대화 문맥 유지, 최종 요청 읽기 및 확인
- 음성 인식: 브라우저 SpeechRecognition (지원 브라우저 한정)
- 음성 출력: 브라우저 SpeechSynthesis (기기별 차이 있음)
- 시리 스타일 애니메이션 및 VoiceOver에서 장식 요소 숨김
- 요청 확정 후 브라우저 localStorage에 임시 저장
- 기존 목록/상품 상세 시연 화면 유지

## 한계 및 테스트 주의

- 아이폰 Safari 등에서 SpeechRecognition 지원 및 권한 동작이 달라질 수 있습니다. 텍스트 답변 버튼으로 AI 연동을 테스트할 수 있습니다.
- VoiceOver와 TTS 음성 충돌은 OS에서 완전히 제어할 수 없습니다. 실제 사용자 테스트가 필요합니다.
- 봉사자 매칭, DB, 상품 리뷰 실데이터, 인증은 미구현입니다. 화면의 상품 상세는 예시 데이터입니다.
- 서버의 세션은 메모리 저장이며 서버 재시작 시 사라집니다. 요청 확정 정보는 브라우저에만 저장됩니다.
- 공개 배포 전 인증, API 사용량 제한, 세션 저장, 로깅/개인정보 처리 보강이 필요합니다.
- 휴대폰 테스트는 HTTPS 배포가 권장됩니다. localhost는 휴대폰에서 PC 서버를 가리키지 않습니다.
