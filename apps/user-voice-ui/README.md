# LightHouse 접근성 MVP

시각장애인 이용자가 여섯 번의 질문에 답해 구매 요청을 등록하고, 요청 내용과 봉사자 응답을 확인할 수 있는 브라우저 데모입니다.

## 실행 방법

Node.js 20.6 이상에서 다음 명령을 실행합니다.

```bash
npm start
```

브라우저에서 `http://localhost:3000`으로 접속합니다. 별도 패키지 설치는 필요하지 않으며, 프로젝트 루트의 `.env`에 `OPENAI_API_KEY`가 설정되어 있어야 합니다.

## 구현 범위

- 첨부 와이어프레임 기반 5개 화면
- 이전 답변을 참고하는 OpenAI 기반 멀티턴 상품 대화
- `첫 번째 질문입니다`부터 `여섯 번째 질문입니다`까지 정확히 여섯 번의 질문
- iPhone Safari 사용자 동작 안에서 마이크 권한 안내 TTS를 즉시 시작
- 최초 실행 시 권한 안내 후 마이크 허용을 완료한 다음 첫 질문 재생
- 질문 TTS 종료 후 자동 음성 인식과 다음 질문 자동 진행
- 질문 시작 후 대화가 끝날 때까지 VoiceOver에서 제외되는 장식용 음성 모션만 표시
- 완료 안내 TTS가 끝난 뒤 요청 확인 화면을 열어 VoiceOver와 AI 음성 중복 방지
- 여섯 질문 완료 후 한 문장 AI 요청 요약과 `이대로 요청하기` 등록
- 최종 요약에서 `요청사항 수정하기`를 선택해 음성으로 조건 수정
- 브라우저 `localStorage`를 이용한 요청 저장
- 요청 ID 기반 요청 상세와 봉사자 응답 연결
- 화면 전환 제목 포커스, 상태 라이브 알림, 44px 이상 터치 영역

## 데모 한계

- 음성 인식 지원 여부와 마이크 권한 정책은 브라우저마다 다릅니다.
- iPhone Safari의 음성 인식을 사용하려면 기기에서 Siri가 활성화되어 있어야 합니다.
- 실제 VoiceOver와 음성 합성 충돌은 iOS 실기기에서 별도로 검증해야 합니다.
- 봉사자 매칭, 인증, 서버 데이터베이스, 실시간 상품 정보는 연결하지 않은 데모입니다.
- 예시 봉사자 응답의 가격과 링크는 실제 구매 정보로 보장하지 않습니다.
