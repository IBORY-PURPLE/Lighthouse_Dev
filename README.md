# LightHouse

시각장애인이 음성으로 상품을 요청하면, 봉사자가 AI 조언을 받아 대신 찾아 주는 모바일 웹 서비스입니다.

> 현재 개발 중인 아이폰(VoiceOver) 기준 MVP입니다. 상용 서비스가 아니며, 공개 전 법적 확인이 필요합니다.

## 어떤 문제를 푸나요

전맹·저시력 시각장애인은 쇼핑몰에서 상품을 검색하고 비교하고 구매 화면을 따라가는 일이 큰 부담입니다. LightHouse는 이 과정을 "말로 요청하고, 사람이 찾아서 알려 주는" 방식으로 바꿉니다.

## 이렇게 동작합니다

1. **요청**: 이용자가 아이폰에서 VoiceOver를 켠 채 음성으로 상품을 말합니다.
2. **탐색**: 봉사자가 쿠팡 등 편한 사이트에서 직접 상품을 찾아 화면 캡처를 올립니다.
3. **AI 조언**: AI는 봉사자의 어시스턴트입니다. 검색어·확인할 조건 제안, 요청과 맞는지 확인, 상세 이미지 요약, 설명문 초안, 혜택·할인 정리만 합니다.
4. **확인과 답변**: 봉사자가 내용을 확인해 후보 1개, 구매 링크, 구매 가이드를 보냅니다.
5. **듣기와 구매**: 답변은 화면 글자로 보여 VoiceOver가 읽고, 원하면 듣기 버튼으로 소리로 들을 수 있습니다. 이용자는 구매 링크를 엽니다.
6. **재사용**: 같은 주소나 비슷한 요청이 오면 이전 설명을 봉사자에게 먼저 보여 줍니다.

## 원칙

- AI가 쇼핑몰에 접속하거나 탐색하지 않습니다. 찾는 일은 사람이 합니다.
- 실제 가격·재고를 지어내지 않고, 구매나 건강 판단을 대신하지 않습니다.
- 자동 결제와 계정 대행을 하지 않습니다.
- 주소·가격·혜택 같은 사실, AI 요약, 봉사자 설명만 저장합니다. 원본 상세페이지와 개인정보는 저장하지 않습니다.
- 이번 MVP에서 봉사자는 팀원이 대신하며, 시연 때 이를 밝힙니다.

## 성공 기준

- 음성 요청부터 답변 듣기, 구매 링크 열기까지 전체 흐름을 실제 서버와 실제 아이폰에서 1회 이상 성공하고 영상으로 남깁니다.
- 실제 상품 10~20개 정답지 기준 핵심 항목 정확도 90% 이상, 지어낸 정보 0건.
- 첫 진행 안내 5초, 답변 10분 이내.
